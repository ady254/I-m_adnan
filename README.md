# ADNAN.OS v2.6

Interactive cyberpunk pixel-art portfolio — boot into Adnan Ahmad's fictional operating system.

## Stack

- React + TypeScript + Vite
- Tailwind CSS v4
- React Router
- Lucide React icons

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Content

Edit files in `src/data/` to update portfolio content:

- `profile.ts` — personal info, about, contact
- `projects.ts` — project listings
- `skills.ts` — tech stack inventory
- `thoughts.ts` — blog/notes
- `innvoxJourney.ts` — Innvox timeline
- `resume.ts` — resume content
- `lazyResponses.ts` — Lazy.exe chatbot responses

## Resume PDF

Place your resume at:

```
public/Adnan-Ahmad-Resume.pdf
```

## Deploy

Static build output in `dist/` — deploy to Vercel, Netlify, GitHub Pages, or any static host.
